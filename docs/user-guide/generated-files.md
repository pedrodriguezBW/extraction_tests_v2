# Archivos generados

## Ubicación del informe

El PowerPoint final se guarda directamente en:

```text
04_Report
```

La aplicación prepara el informe en:

```text
04_Report/_Working
```

Cuando la generación termina correctamente, el archivo completo queda disponible en `04_Report`.

## Recursos renderizados

Las gráficas SIMPATI guardadas se conservan en:

```text
04_Report/_RenderedAssets
```

Estos recursos pueden incorporarse a la sección `Test Results` del PowerPoint.

## Revisión posterior

Después de generar el informe:

1. Abre el PowerPoint indicado por la aplicación.
2. Revisa los datos identificativos del ensayo.
3. Revisa las piezas, el montaje y los inputs.
4. Comprueba las evidencias y gráficas de `Test Results`.
5. Completa o modifica manualmente la diapositiva `Conclusions`.
6. Guarda la versión revisada siguiendo el proceso de trabajo del ensayo.

El informe generado permanece editable.

## Regeneración

Si necesitas regenerar el PowerPoint, revisa primero si existe una versión editada manualmente que debas conservar. La guía técnica documentará con detalle la política de nombres y sobrescritura cuando se cierre ese contrato de comportamiento.
